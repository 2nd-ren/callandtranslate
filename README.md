# Call & Translate

Get things done in a language you don’t speak. Brief a live caller, put the phone on speaker, follow a transcript in your language, and keep a report when you hang up.

- Free: browse the app (new accounts start with **zero** credits)
- Paid: £12 / month for **one hour** of call time (3,600 credits, 1 credit = 1 second)

See `docs/DEPLOY.md` for DNS, mail, and Stripe.
